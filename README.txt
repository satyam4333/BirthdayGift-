RUPA BIRTHDAY SURPRISE — UPDATED

Audio flow:
1. Rupa taps "Open Your Surprise".
2. The uploaded birthday-voice.m4a plays first (about 4.1 seconds).
3. Then the uploaded background-song.mp3 starts automatically and loops.
4. The song continues while she moves through the pages.

All assets are local:
- index.html
- rupa-photo.jpeg
- birthday-voice.m4a
- background-song.mp3

For testing: keep all four files in the same folder and open index.html.

For sending to Rupa: upload the entire folder/ZIP to a static host. Do not upload only index.html, because the photo and audio files are required.

Browser note: the first tap is intentionally required because mobile browsers normally block audio autoplay before a user interaction. After that tap, the birthday audio and then the song are started by the page.
